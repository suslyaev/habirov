# Иконки PWA

Создайте следующие иконки для PWA:

1. **icon-192.png** - размер 192x192 пикселей
2. **icon-512.png** - размер 512x512 пикселей

## Как создать:

### Вариант 1: Через Figma/Photoshop
1. Откройте `icon.svg` в редакторе
2. Экспортируйте в PNG нужных размеров

### Вариант 2: Онлайн конвертер
1. Откройте https://cloudconvert.com/svg-to-png
2. Загрузите `icon.svg`
3. Укажите размер 192x192 и 512x512
4. Скачайте и переименуйте

### Вариант 3: Через командную строку (ImageMagick)
```bash
convert icon.svg -resize 192x192 icon-192.png
convert icon.svg -resize 512x512 icon-512.png
```

### Вариант 4: Через браузер
Откройте `create_icons.html` в браузере - он автоматически создаст и скачает иконки.

## Временные заглушки

Пока можно использовать emoji как временную иконку.
