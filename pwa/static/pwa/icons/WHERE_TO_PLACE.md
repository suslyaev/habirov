# Где должны лежать иконки для PWA

## 📍 Расположение файлов

Все иконки должны находиться в папке:
```
pwa/static/pwa/icons/
```

## 📦 Необходимые файлы

Для правильной работы PWA нужны следующие файлы:

1. **icon-192.png** (192×192 пикселей) - основной размер для Android
2. **icon-512.png** (512×512 пикселей) - основной размер для iOS и больших экранов
3. **icon-16.png** (16×16 пикселей) - favicon для браузера (опционально)
4. **icon-32.png** (32×32 пикселей) - favicon для браузера (опционально)
5. **icon.svg** - векторная иконка для современных браузеров (опционально)

## 🔗 Как они используются

### В манифесте (`manifest.json`)
Пути указываются как: `/static/pwa/icons/icon-192.png`
- Django автоматически обслуживает файлы из `pwa/static/` по пути `/static/`

### В HTML (`app.html`)
Используются Django template tags: `{% static 'pwa/icons/icon-192.png' %}`
- Django автоматически подставляет правильный путь

## ✅ Проверка

После размещения файлов проверьте:

1. **Файлы физически существуют:**
   ```bash
   ls -la pwa/static/pwa/icons/icon-*.png
   ```

2. **Доступны по URL:**
   - `http://ваш-сервер/static/pwa/icons/icon-192.png`
   - `http://ваш-сервер/static/pwa/icons/icon-512.png`

3. **В манифесте:**
   - Откройте `http://ваш-сервер/manifest.json`
   - Проверьте, что пути к иконкам правильные

4. **После изменений:**
   - Выполните `python manage.py collectstatic` (если `DEBUG=False`)
   - Обновите страницу в браузере
   - Переустановите PWA на рабочий стол

## 🎨 Генерация иконок

Используйте файл `create_icons_browser.html` для генерации всех размеров:
1. Откройте в браузере
2. Скачайте все иконки
3. Сохраните в `pwa/static/pwa/icons/`
